# David Poussif - Personal Website

A simple, responsive personal portfolio website built with HTML and CSS. 

## Features

* **Modern Design:** Clean, modest aesthetic.
* **Quick Links:** Direct access to GitHub, Streamlit projects, and LinkedIn.
* **Resume Access:** One-click download for the latest CV.
* **Responsive Layout:** Built with CSS Flexbox to ensure it looks great on both desktop and mobile devices.
* **Custom Icons:** Utilizes Font Awesome and Simple Icons for scalable vector graphics.
